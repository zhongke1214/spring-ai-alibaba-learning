# 退款政策技能

1. 先调用 `query_order` 查清订单状态与金额，再判断是否可退。
2. 已支付（paid）且 `refundable=true` 才可发起退款；已发货订单需提示用户先确认收货或走售后。
3. 涉及真实退款必须调用 `refund_order`，禁止口头承诺「已经退款」。
4. 退款金额不得超过订单金额；用户未说明金额时，默认按订单金额申请。
5. 禁止承诺「一定能退」「马上到账」等无法保证的时效。
